## Windows x64 三档安装包

| 包型 | 随包组件 |
| --- | --- |
| 轻量包 `MisaTV-windows-x64-lite.zip` | 主程序与默认播放器。扩展运行时按需安装。 |
| 标准包 `MisaTV-windows-x64-standard.zip` | 裁剪版 JRE 17、dex2jar、JVM 宿主库、加固壳支持和 Python 解释器。Python 第三方库与 Yaozhi MPV 按需安装。 |
| 完整包 `MisaTV-windows-x64.zip` | JVM、加固壳支持、Python 及依赖库、Yaozhi MPV 整合包，首次启动可离线初始化。 |

- 应用内更新会沿用当前包型。已有轻量包和完整包用户可直接更新并保留 `userdata/`。
- 首次使用标准包时，可下载对应 ZIP 解压到新目录。后续可通过应用内更新获取同包型的版本。
