基于官方 MisaTV 1.3.0，包含自 fork v1.2.0.2 以来的更新。

## 新增功能

- Android APK 内置 CPython 3.12 和所需依赖，导入 Python 蜘蛛源后即可使用。
- Android 支持 TVBus P2P 直播，可播放用户导入的兼容 `tvbus://` 频道。
- 新增迅雷云盘和光鸭云盘支持，扩展网盘站源的登录和播放能力。
- Windows 轻量版中，通过设置安装的 Yaozhi MPV 可在设置页检查和安装更新。

## 修复与改进

- 改善 115 网盘的登录状态校验，修复部分网盘源的中继子路径和视频尾部拖动问题。
- 改善夸克、UC 和百度网盘取流兼容性，并改进 WebDAV 目录解析与同步。

## Windows 下载与升级

- 完整版 ZIP 随附 JVM、加固壳支持、Python 和 Yaozhi MPV，运行时可从本地初始化。轻量版 ZIP 在使用相关功能时按需安装运行时。
- 应用内更新会优先使用与当前版本和包型匹配的差异包，保留 `userdata/`。缺少匹配差异包时可下载对应包型的完整 ZIP。
